# Ethical Use of LLMs (AI)

ChatGPT was used for coding assistance. The framework was developed according to the author's original wolfram mathematica implementation which includes the necessary algorithmic steps for already Carleman linearising PDEs based on F1 and F2 input. The python conversion was carried out for opensource and efficiency purposes. Throughout the conversion, line by line, loop by loop, under strict supervision, ChatGPT was used for converting the syntax. No logic, or intellectual property, was designed by an LLM.
